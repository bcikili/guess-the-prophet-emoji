# 🌟 Guess the Prophet with Emojis 🕌

A fun and educational emoji-based guessing game created for and designed by **Ihsan** (age 11)!

---

## 🎯 Game Concept
Players look at a set of emoji clues representing stories, miracles, or symbols associated with Prophets, and guess which Prophet the clues refer to!

### Example Clues
- 🚢 🌊 🕊️ 🌧️ ➡️ **Prophet Nuh (Noah) (AS)**
- 🐋 🌊 🌙 🤲 ➡️ **Prophet Yunus (Jonah) (AS)**
- 🐑 🔪 🏔️ 🕋 ➡️ **Prophet Ibrahim (Abraham) (AS)**
- 🦯 🐍 🌊 👑 ➡️ **Prophet Musa (Moses) (AS)**
